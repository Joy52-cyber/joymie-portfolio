NativeEyeQA

An AI mobile test automation tool for the 80% of QA who don't write code. Plain-English test cases get translated into mobile actions at runtime, with vision-based self-healing when selectors break. Born from the manual-to-automation gap I lived through coordinating QA at a mobile games studio.

  • Plain-English test cases — manual testers automate flows without writing Appium code
  • Vision-based self-healing — when a selector fails, Claude re-identifies the element from a screenshot
  • PRD ingestion — paste requirements, auto-generate runnable test cases
  • Multi-device parallel execution across Android (UiAutomator2) and iOS (XCUITest)
  • AI-classified bug reports with severity, root cause, and PRD-requirement traceability, persisted to SQLite
  • "Magic Fill" — AI-generated form data per field type
  • Stack: C# / .NET 8, WPF (MVVM), Appium 2.x, Claude 4.6 with prompt caching, OpenAI fallback, SQLite, Serilog, Polly resilience, 428-test MSTest suite

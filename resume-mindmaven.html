Automation & Product Projects

SlashCal — AI Scheduling & Coordination Automation 2025 – Present · slashcal.com

Two production automation systems I built and operate solo with Claude Code. Both take real operational work (scheduling coordination, inbox handling, follow-ups) and run it end to end.

  • Email scheduling assistant: inbound guest emails hit a Mailgun webhook, an LLM parses intent, the system generates open calendar slots and auto-replies with times, then runs a thread state machine (observe → propose → nudge → book) with 24-hour follow-up nudges, no-show detection, and confidence-gated auto-booking. Automates the exact back-and-forth an EA does by hand.
  • Automation engine behind it: a database-backed job scheduler (11 job types on independent cadences, 60-second poll loop, stuck-task watchdog) running multi-step email and follow-up sequences, IMAP reply detection with 14-way LLM intent classification, and a nightly learning loop. Event-driven, with OAuth, per-timezone send windows, rate-limit guardrails, and Slack alerts scoped to high-signal events only.
  • Stack: Node.js, PostgreSQL, Claude (Haiku / Sonnet) with Gemini fallback, Gmail SMTP/IMAP, Google Calendar, Slack webhooks, Mailgun, Stripe, deployed on Railway.
NativeEyeQA — AI Mobile Test Automation 2026 – Present · C# / .NET 8, Appium, Claude / OpenAI

Desktop tool that lets QA engineers write mobile tests in plain English.
